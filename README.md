# 🍔 FoodMunch - Dynamic Food Ordering Website

A responsive and dynamic food ordering website built with HTML, CSS, and JavaScript. Users can search, filter, and order food with a live cart system.

## ✨ Features

- 🔍 **Live Search** - Search food by name instantly
- 🥗 **Category Filter** - Veg, Non-Veg, Desserts
- 🛒 **Dynamic Cart** - Add, Remove, Clear Cart
- 💰 **Live Total** - Auto calculates total price
- 📱 **Responsive Design** - Works on Mobile & Desktop
- 🎨 **Purple Theme** - Modern & attractive UI
- ⚡ **Bootstrap 4** - Fast and clean layout

## 🛠️ Tech Stack

- **HTML5** - Structure
- **CSS3** - Custom Styling
- **JavaScript (Vanilla JS)** - Dynamic Logic
- **Bootstrap 4.5.2** - Responsive Framework

> All 3 files must be in the SAME folder!

## 🚀 How to Run

1. Create a folder `food-munch`
2. Create 3 files inside: `index.html`, `style.css`, `script.js`
3. Copy respective codes into files
4. Right Click on `index.html` > **Open with Live Server**
5. Or Double Click `index.html` to open in browser

## 🔧 Functionality Explained

### `display()` 
Renders all food cards dynamically

### `doSearch()`
Filters food based on search input

### `filterCat()`
Filters by category - veg / nonveg / dessert

### `addToCart() / removeCart() / clearCart()`
Manages cart operations

### `updateCart()`
Updates cart count and total price in navbar and cart panel
